# Civic ParkTube Android 16
Personal YouTube browser app, built with Android SDK 35, Java 17.
This APK runs on an Android phone. Android Auto's app approval and vehicle safety rules may prevent it from appearing on a Honda Civic 2024 head unit. It does **not** bypass driving video interlocks.
Build: `gradle :app:assembleDebug`.
Use in a parked vehicle only. Not affiliated with Honda, Google, or YouTube.
